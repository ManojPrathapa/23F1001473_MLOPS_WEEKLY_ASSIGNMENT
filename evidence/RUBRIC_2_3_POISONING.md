# Rubric 2 & 3: Data Poisoning and MLflow Tracking

- **Execution:** Successfully simulated data poisoning at 0%, 5%, 10%, and 50% corruption levels.
- **Method:** Replaced random indices in the training set with random uniform feature noise and random labels.
- **Tracking:** Logged Accuracy, Precision, Recall, and F1 Score to MLflow.
- **Evidence:** Captured in MLflow UI screenshot showing model degradation.
